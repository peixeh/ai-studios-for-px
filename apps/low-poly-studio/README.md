# Low Poly Studio — migração planejada

Os estudos originais geram vértices, triângulos e cores por JavaScript, exibem as malhas em Canvas e animam a boca com formas interpoladas. O chapéu também possui exportação OBJ.

Antes de extrair a aplicação: separar o visualizador e os controles das funções de cada modelo; oferecer uma cena genérica; documentar a exportação. A implementação genérica ainda não foi migrada para esta pasta.
